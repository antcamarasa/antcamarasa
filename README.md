### ⚡⚡ Short cut makes long delay. ⚡⚡

**FACT #1** : un framework change tous les trois ans. Un pointeur, c'est un pointeur depuis 1972.

**FACT #2** : une IA génère une API Spring en dix secondes. Quand on ne comprend rien, la déboguer prend des semaines.

**FACT #3** : coller son erreur dans un LLM, ce n'est pas du debugging. C'est de la prière. 💀

**FACT #4** : les ingénieurs logiciels de demain seront ceux qui comprennent comment les systèmes fonctionnent. Pas ceux qui savent écrire un prompt.

### 🧱 La stratégie

Recoder ce que les outils me cachent : les structures de données, un shell, un allocateur mémoire, un serveur, une base de données.

L'IA reste un outil. Si je ne suis pas capable de relire ce qu'elle a écrit, quel est mon rôle ? Aucun.

Ce n'est pas le chemin le plus rapide. C'est celui qui dure.
